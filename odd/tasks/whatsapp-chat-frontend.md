# WhatsApp chat integrated in the CRM — frontend only

Objective: build the frontend of the WhatsApp integration designed in the "Chat integrado CRM" canvas, backed by in-memory mock data behind a repository port so the backend can be plugged in later.
Branch: `feat/whatsapp-chat-frontend` · Delivery: ask-on-risk · Test runner: `node --test tests/whatsapp-*.test.mjs` (Node 26 native TS stripping) + `npm run lint` + `npm run lint:design` + `npm run build`.

## Specs

- S1 — "Me gustaria que armaramos primero el diseño (frontend) y despues vemos como conectamos el backend". No Supabase tables, migrations, or external WhatsApp provider calls in this feature. Data comes from a mock adapter behind a `ConversationRepository` port (assumption: in-memory, resets on reload).
- S2 — Conversation states from the design board "Estados y tipos de mensaje": `1 · Con asistente`, `2 · Esperando vendedor`, `3 · Atendiendo tú` ("Asistente en pausa" with a countdown; "Al tomarla, el asistente se pausa por 60 min y respondes tú."; "Si vence el plazo, el asistente retoma solo."), `4 · Cerrada` ("Si el cliente vuelve a escribir, la conversación se reabre con el asistente y queda en la misma ficha."). Actions: "Tomar conversación", "Devolver al asistente", "Cerrar", "Ver historial".
- S3 — Message types: Cliente, Asistente, Vendedor desde el CRM, Vendedor desde el teléfono ("Enviado desde el teléfono"), Archivo (e.g. "Cotización OP-2026-6056.pdf · 340 KB"), Eventos del sistema ("Derivado a Ventas · asignado a Jesus por turno", "Jesus tomó la conversación", "Plazo vencido · el asistente retomó"). Delivery ticks ✓ / ✓✓.
- S4 — Opportunity window ("Ventana de la venta · pestaña WhatsApp"): the activity column gets an `Actividad` / `WhatsApp` switch with an unread badge; the WhatsApp view shows contact header (name, phone, state chip), "Tomar conversación" button, thread, "1 MENSAJE NUEVO" divider, and a composer locked with "Toma la conversación para responder al cliente." while the assistant is in charge. Opportunity summary shows "Datos capturados por el asistente" when the opportunity came from WhatsApp.
- S5 — Inbox ("Bandeja de conversaciones"): new sidebar item "Conversaciones" with unread count, filters "Mis chats", "Esperando", "Con asistente", "Cerrados"; conversation list with state pill and unread count; thread with quick replies ("Agendar visita a terreno", "Enviar ficha técnica", "Cotización en preparación") and hint "Se envía por WhatsApp desde el número de Hormiglass"; right panel with Cliente, Oportunidad, "Capturado por el asistente" and "Abrir oportunidad"; assignment notice "Nuevo cliente asignado a ti" in the existing notification center reached by the bell, with access to the matching demo chat (supersedes the inbox banner per L23).
- S6 — Seller notifications: "Nuevo cliente asignado a ti", "Tu plazo vence en 5 min", "El asistente retomó una conversación" (frontend surface only; assignment appears in the existing notification center/bell, while warning/resumption remain in-app inbox notices; never persisted in `notificaciones`).

- S7 — "Se ve bien, pero hay que ajustar el layout. Instala las herramientas necesarias para que tu puedas visualizarlo, o tambien puedes ocupar el browser integrado de Orca, para que lo visualices". User refinement: "Quedó mejor, pero igualmente se ve feo, ajusta bien los tamaños de todo y ajusta bien el responsive". Latest clarification: "Me refiero a que se vea un poco mas ajustado, me refiero a que el la burbuja del texto sea mas acotada al mensaje, el cuadro de del chat un poco mas ajustado, Tal vez tambien que sea un poco mas alto. Esto es con el fin de que los laterales se vean con mas espacio y se vea mejor visualmente". Inspect actual frontend components visually before layout changes; refine overall sizing, density and responsive behavior, including intermediate widths and shorter viewports. Use project-local browser tooling; preserve mock-only and no-production constraints.

- S8 — "Ahora me gusta mucho mas, Pero me gustaria cambiar las barras de scroll, a que sean mucho mas minimalistas y delgadas y tambien yo creo que el banner de nuevo cliente asigando a ti, deberia ir en el boton de notificaciones".
