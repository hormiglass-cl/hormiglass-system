## Specs

- S1 — Layout like WhatsApp: "hazme una ultima propuesta y esta quiero que la hagas parecida a la pagina de whatsapp, a la pagina de conversaciones". Edge-to-edge panes: chat list | chat | customer card ("Ficha del cliente"), header bars of equal height, pill search and pill composer.
- S2 — More intuitive: "me gusta mas, pero intenta de hacerla un poco mas intuitiva". As drawn in H: list grouped by who must act ("TE ESPERAN", "ATENDIENDO TÚ", "CON EL ASISTENTE", plus "Ver chats cerrados"); a status banner with the next step ("… te espera hace N min." + "Tomar chat"; when attending: "Estás atendiendo a …" + countdown + "Devolver al asistente"); author label on every message ("Cliente", "Asistente", "Tú"); labeled quick actions ("Cotizar", "Enviar ficha técnica", "Agendar visita") instead of icon-only controls.
- S3 — Colorful: "y que se vea mas colorido y vivido". Accent-orange chat header, warm chat background, strong-colored avatars and count badges, each list group and quick action with its own status color.
- S4 — CRM colors only: "pero ocupa los colores del crm". Only tokens from `app/globals.css` (accent, accent-ink, text, night, success, warning, info, violet and their soft/border variants); `npm run lint:design` must pass.
- S5 — Approval: "me gusta la propuesta H". Match the H artboards for both sidebar states (collapsed: card open beside the chat; expanded: card closed by default, opened with "Ficha del cliente").
- S6 — Preserve existing behavior (assumption, implied by redesign scope): claim/release/close, history, quote and datasheet shortcuts, unread divider, notices, mobile one-pane flow, keyboard access, and the responsive fixes committed in `5b6c779`.

- S7 — Design contract (parent assumption derived from the H artboards; user-facing strings in Spanish, code/comments in English; Tailwind token classes only — `bg-accent`, `text-on-accent`, `text-accent-ink`, `bg-accent-soft`, `border-accent-line`, `bg-night`, `text-night-ink`, `success|warning|info|violet` with `-soft`/`-line`, `text-ink`, `text-ink-muted`, `bg-surface`, `bg-surface-muted`, `border-line`, `border-line-subtle`; no raw hex; every font ≥ 11px; touch targets ≥ 40px):
  - S7.1 Chat workspace (`components/whatsapp/ChatWorkspace.tsx`, `ChatPrimitives.tsx`): `ChatWorkspace({ conversationId, detailsOpen?, onToggleDetails? })`. Header: full-width `bg-accent text-on-accent` bar (h ≈ 60px) with avatar, contact name (h2), phone + opportunity code line, a "Ficha del cliente" button (only when `onToggleDetails` is given; `aria-pressed={detailsOpen}`, `aria-controls="chat-customer-details"`), and the existing keyboard-accessible actions menu (`aria-label="Acciones del chat"`, items as today: "Devolver al asistente" (seller), "Cerrar" (not closed), "Historial") with visible text "Opciones". "Tomar chat" leaves the header.
  - S7.2 Status banner (new `ChatStatusBanner`, rendered by the workspace between header and thread, `role="status"`): waiting → warning tone, "**{first name} te espera hace {N} min.** Tómalo para responderle tú: el asistente se pausa 60 minutos." + accent pill button "Tomar chat"; assistant → info tone, "**{first name} está con el asistente.** Tómalo si quieres responderle tú: el asistente se pausa 60 minutos." + "Tomar chat"; seller → success tone, "**Estás atendiendo a {first name}.** Si no respondes en {m:ss}, el asistente vuelve a tomar el chat." + outlined success button "Devolver al asistente"; closed → neutral, "Conversación cerrada. Si el cliente vuelve a escribir, se reabre con el asistente." (no button). N = whole minutes since the last customer message (min 1).
  - S7.3 Thread: warm `bg-accent-soft` background with a subtle dotted pattern; every non-event message shows its author label: customer "Cliente" (success), assistant "Asistente" (accent-ink, bubble `bg-accent-line`), seller "Tú" (success; white bubble with 2px success border), phone "Tú · desde el teléfono", file "Archivo de demostración" (keep "▤ " prefix and "Vista de ejemplo · archivo no disponible para descargar"). Events: centered rounded pills (info tone for handoffs). Keep the unread divider, `<time>` per message, delivery ticks with aria-labels "Leído"/"Enviado", list name "Mensajes de demostración".
  - S7.4 Composer: quick actions group `aria-label="Acciones rápidas"` with labeled pill buttons "Cotizar" (info), "Enviar ficha técnica" (violet), "Agendar visita" (success; fills the draft as today, disabled when locked); below, a pill textbox (accessible name "Mensaje de demostración"; placeholder locked "Toma el chat para escribir", unlocked "Escribe tu respuesta…") and a round accent send button (accessible name "Enviar"). Keep the small "Demo: no se envían mensajes reales." disclosure.
  - S7.5 Avatars (`ContactAvatar`): strong token backgrounds (`bg-success`, `bg-info`, `bg-violet`, `bg-accent-ink`, `bg-warning`) with white text, chosen by name hash as today.
  - S7.6 Chat list (`ConversationList` in `components/whatsapp/InboxParts.tsx`) — REVISED by L6 ("en la parte de los chats que sea como la propuesta G, pero manteniendo los colores de ahora"; clarified: "La lista de chats"): like proposal G — one flat list, no grouped sections and no closed-chats toggle. Edge-to-edge white column; header "Chats" (h2) + "Demo" info pill; pill searchbox "Buscar conversaciones" (placeholder "Buscar nombre, teléfono o empresa"); a single-row filter pill tablist (`aria-label="Filtrar chats"`) with tabs "Todos", "No leídos" (unread > 0), "Esperando {n}" (waiting; n = waiting count, omitted when 0) and "Míos" (seller); selected tab `bg-accent-soft text-accent-ink`, others outlined. Rows ordered waiting, seller, assistant, closed (stable within a state). Row: avatar 46px, name, time (waiting: "hace {N} min" in accent-ink; else `formatListTimestamp`), preview line — waiting: "Esperando vendedor · " in warning + last text; closed: "Cerrada · " + last text; otherwise prefixed "Tú: " for seller/phone and "Asistente: " for assistant messages — unread badge + sr-only "{n} sin leer · demo". Selected row: `bg-accent-soft` with a 4px inset accent bar (success bar when seller). Search and filter combine; empty result keeps the EmptyState "Sin conversaciones". Current CRM colors stay.
  - S7.7 Customer card (`ConversationDetails({ chat, onClose? })`): header bar `bg-night text-night-ink` "Ficha del cliente" (h2) with a close button "Cerrar ficha del cliente" when `onClose` is given; identity block `bg-success-soft` with 80px avatar, name, company; rows "Teléfono", "Oportunidad" (code); "El asistente capturó" heading (info) with captured values as info-soft chips; accent pill button "Abrir oportunidad" (same `aria-expanded` summary toggle and region "Resumen de oportunidad demo" as today); small "Demo · ficha sin vínculo real" note.
  - S7.8 Page (`app/conversaciones/page.tsx`): edge-to-edge panes filling the area under the navbar; keep container-query pane logic (three panes when the page is ≥1120px wide, otherwise list | chat with the card toggled from the chat header, one pane on phones with "Volver a la lista"), notices, demo notice handling and thread requests from notifications.
